# 01 — Governance

Aturan pengelolaan proyek, approval gate, ownership, scope control, dan perlindungan production.

## Prinsip wajib
- `main` adalah production branch.
- Production tidak diubah langsung.
- Perubahan besar melalui branch + pull request + QA.
- Deploy production hanya setelah persetujuan eksplisit.
- Rahasia, kredensial, dan konfigurasi sensitif tidak ditulis ke dokumentasi publik.
