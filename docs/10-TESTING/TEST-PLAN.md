# Test Plan

## Mandatory smoke checks
- Halaman utama terbuka.
- Navigasi bekerja.
- Booking form dapat diisi dan dikirim.
- Armada tampil.
- Pembayaran tampil.
- WhatsApp CTA bekerja.
- Asisten AI dapat dibuka.
- Tidak ada error JavaScript kritis.
- Mobile layout tidak clipping.
- Metadata SEO dan canonical benar.
- Production workflow hanya dapat deploy dari `main`.

## Regression principle
Setiap perubahan UI wajib diuji terhadap core functionality yang sudah ada.
