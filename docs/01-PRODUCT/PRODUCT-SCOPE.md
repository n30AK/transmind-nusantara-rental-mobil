# Product Scope

## Core
- Landing/marketing website
- Armada
- Pemesanan
- Harga dan layanan
- WhatsApp
- Asisten AI
- Analytics
- SEO
- Nexus
- Integrasi Supabase/API yang sudah ada

## UX direction
Website menggunakan pendekatan premium automotive/mobility: dark OLED, Liquid Glass, editorial typography, cinematic media, floating navigation, booking command center, dan pengalaman mobile-first.

## Non-goals
- Mengganti backend hanya demi perubahan visual.
- Memindahkan production ke Vercel.
- Mengubah database tanpa kebutuhan dan dokumentasi.
