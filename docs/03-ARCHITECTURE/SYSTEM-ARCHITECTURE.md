# System Architecture

## Layers
1. Presentation — index.html, CSS/UI architecture, responsive behavior.
2. Client logic — app.js dan modul JavaScript.
3. Data/service — Supabase dan API/integration modules.
4. Conversion — booking, WhatsApp, attribution.
5. Intelligence — Asisten AI dan Nexus.
6. Delivery — GitHub repository + GitHub Pages.

## Production boundary
`main` adalah production source. Staging/development branch tidak boleh menjadi Pages publishing source.
