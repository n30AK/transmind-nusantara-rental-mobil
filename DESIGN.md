# TransMind UI Next — Staging Design Context

## Product
TransMind Nusantara — intelligent mobility and travel platform.

## Audience
Customers seeking premium vehicle rental, driver services, travel planning, accommodation and corporate/event transport.

## Page job
Turn the homepage from a conventional rental landing page into a premium intelligent travel entry point while preserving existing booking, fleet, WhatsApp, AI Companion and Nexus integrations.

## Visual direction
- Dark premium foundation: near-black / graphite.
- TransMind cyan-blue as the functional accent.
- Glass surfaces used sparingly.
- Typography: Space Grotesk for display/UI and Inter for supporting copy.
- Large cinematic composition with disciplined information density.
- One signature element: AI Companion panel with a human avatar treatment.

## Durable tokens
- Ink: #070A0F
- Surface: #0D121A
- Surface elevated: #121A24
- Line: #243140
- Text: #F4F8FC
- Muted: #8EA0B5
- TransMind cyan: #39C6FF
- TransMind blue: #1677FF
- Success: #39D98A
- Radius: 18px cards / 12px controls
- Motion: 180–500ms, respect prefers-reduced-motion

## Behavioral contract
Prototype only. No production route, domain, database, Supabase auth, booking RPC, analytics, Nexus, or existing public page is modified by this UI prototype.

## Approval gate
Production migration requires explicit user approval.
